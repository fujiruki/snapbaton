# 06. 変更履歴

## 2026-08-30: 画像エディタ起動時の白画面バグ修正
- グループ詳細画面で画像サムネイルをクリックするとエディタが開かず白画面になる不具合を修正
- 原因: `@fujiruki/react-image-editor-lightbox`（`file:`リンク参照）側の`node_modules`にReact 18.3.1が、admin側にReact 19.2.4が存在し、Reactが二重に読み込まれていた（`useRef`のdispatcherがnullになりReactツリー全体がクラッシュ、エラーバウンダリが無いため白画面に）
- `admin/vite.config.ts`に`resolve.alias`を追加し、react/react-domを単一パスに強制することで解消
